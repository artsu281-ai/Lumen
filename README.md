# Lumen

Яркость встроенного Liquid Retina XDR на MacBook Pro до пика панели (1600 нит) и вниз до 2 нит —
одной шкалой, клавишами F1/F2 и из строки меню. Без слоя поверх картинки, поэтому Cmd+Tab
и Mission Control яркость не сбивают.

Повторяет «прямое масштабирование XDR» из BetterDisplay 5, разобранное по его бинарнику:

- яркость пишется в нитах в свойство `IOMFBBrightnessLevel` фреймбуфера (16.16, ниты × 65536);
- экран на время работы переводится на пресет без HDR «Apple Display (P3-600 nits)» —
  на пресете XDR WindowServer сам держит подсветку и перетирает запись;
- потолок `BLNitsCap`, который система на этом пресете опускает до 600, поднимается до пика;
- автояркость выключается, F1/F2 перехватываются (нужен Универсальный доступ).

При выходе (и по `kill`) возвращаются исходный пресет, автояркость и системная яркость.
Клавиши F1/F2 перехватываются, только пока Lumen держит панель и курсор на встроенном экране.
Когда macOS сообщает о сильном нагреве, яркость временно ограничивается 1000 нит (при
критическом — 600): 1600 нит — пик панели, на весь экран надолго Apple обещает 1000.

### Если Lumen закрыли принудительно

После «Завершить принудительно» или падения экран остаётся на пресете P3-600 без автояркости
до следующего запуска Lumen — он вернёт всё сам. Если запускать его больше не нужно:

    /Applications/Lumen.app/Contents/MacOS/Lumen --restore

или вручную: Системные настройки → Мониторы → пресет «Apple XDR Display (P3-1600 nits)»,
затем включить «Автоматически настраивать яркость».
Подробности, замеры и тупики — в [xdr-памятка.md](xdr-памятка.md).

## Сборка

    ./build.sh            # → build/Lumen.app
    ./build.sh --install  # → /Applications/Lumen.app и запуск

Подписывается сертификатом Apple Development, если он есть, — тогда Универсальный доступ
не слетает после пересборки.

## Ограничения

- Только встроенный XDR-дисплей Apple silicon; проверено на MacBook Pro M5 Pro, macOS 27.
- Приватные API (CoreDisplay, DisplayServices, свойства IOMobileFramebuffer) — могут сломаться
  с обновлением macOS.
- Пока Lumen держит панель, HDR недоступен (пресет без HDR), а автояркость, ползунок яркости
  в Пункте управления и выбор пресета в macOS не действуют. Сменили пресет в Системных
  настройках сами — Lumen это поймёт и отдаст панель.
- Вместе с прямым режимом BetterDisplay не работает: пока BetterDisplay запущен, Lumen
  уступает ему панель и берёт её обратно, когда тот закроется.

## Устройство

| Файл | Что делает |
|---|---|
| `src/Panel.swift` | фреймбуфер, пресеты, автояркость, системная яркость |
| `src/Brightness.swift` | шкала, плавные переходы, сторож, захват и возврат панели |
| `src/MediaKeys.swift` | перехват F1/F2 |
| `src/HUD.swift` | индикатор при нажатии клавиш |
| `src/MenuPanel.swift`, `src/main.swift` | меню в строке меню |
| `probe/` | зонды, которыми снимались приватные API |
| `attic/` | ранняя попытка писать свой пресет (macOS это блокирует) |
